## Analysis Notes

### Index barrels (ranks 1–2)

`homeassistant/tools/index.ts` and `todoist/tools/index.ts` are barrel re-exports (`export * from './...'`). Stryker generates 1 mutant each (the `export` statement) which no test exercises. Action: add `"!extensions/**/index.ts"` exclusions to the `mutate[]` array in `stryker.conf.json` to stop polluting the score with noise.

### Python gate failure (rank 4)

`cloud/outbox.py` drives the 35.37% Python aggregate below the 40% break threshold. The outbox module handles cloud-sync retry/dequeue for the Pi — logic is mission-critical but tests mock away the retry state machine entirely. This is the single highest-priority fix to unblock the mutation gate.

### HA and Obsidian (ranks 3, 5–8)

The HomeAssistant and Obsidian extension tools share a pattern: HTTP call paths are mocked at the transport layer, so mutants in argument-building and response-parsing code are never reached by the mock-based tests. The fix is not more mock tests — it is tests that pass real argument objects and assert on the exact request payload Stryker can inject into.
